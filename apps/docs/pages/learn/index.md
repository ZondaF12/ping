# Learn

Short guides for wiring **Ping** into your setup. Everything here uses the same webhook: `https://ping-production-9dc3.up.railway.app/v1/YOUR_SECRET`.

- [Send with cURL](/learn/curl) — quick tests from the terminal
- [JSON body](/learn/json) — structured alerts with title and URL
- [GET in the browser](/learn/browser-get) — no tools required

When you are ready to try a real request from this site, use [Try](/try).
